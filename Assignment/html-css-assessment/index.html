Section 1: 10 Useful HTML Tags

Here are 10 HTML tags that I think are the most useful:

  • <div> - A box that groups elements together. I use it a lot for layout.
  • <span> - Like div but stays inline. Good for styling part of a sentence.
  • <p> - For writing paragraphs of text.
  • <a> - Creates a link. You need href to set where it goes.
  • <img> - Shows an image. You set the file path in src.
  • <h1> to <h6> - Headings. h1 is the biggest, h6 is the smallest.
  • <ul> and <li> - Makes a bullet list. ul is the list, li is each item.
  • <input> - A field where users can type something, like a form.
  • <button> - A clickable button, usually used with JavaScript.
  • <form> - Groups input fields so users can submit data.

Section 2: Important Tags for SEO

I looked up which tags help with SEO (how Google finds your site). Here are the ones I found:

  • <title> - The page title that shows up in Google results. This is the most important one.
  • <meta name="description"> - A short description shown under the title on Google.
  • <meta name="keywords"> - Keywords that describe what the page is about.
  • <meta name="robots"> - Tells Google whether it should index this page or not.
  • <meta name="viewport"> - Makes the site look good on phones. Google cares about this.
  • <h1> - The main title of the page. Google reads this to understand what the page is about.
  • <h2> to <h6> - Sub headings help organize the page. Google uses them too.
  • <a href="..."> - Links to other pages help Google find more content on your site.
  • <img alt="..."> - The alt text explains what the image is. This helps with image search.
  • <link rel="stylesheet"> - Linking an external CSS file keeps HTML small, which helps load speed.

Section 5: Font Sizes - Absolute and Relative

Same sentence shown 6 times with different font sizes using inline styling.

  • 10px (absolute) - "Hello, I am learning HTML." - Absolute: always exactly 10px no matter what.
  • 20px (absolute) - "Hello, I am learning HTML." - Absolute: always exactly 20px. Bigger than 10px.
  • 0.8rem (relative) - "Hello, I am learning HTML." - Relative: 0.8 x 16px = about 12.8px. Changes if the user changes their browser font size.
  • 1.2rem (relative) - "Hello, I am learning HTML." - Relative: 1.2 x 16px = about 19.2px. rem is based on the html element font size.
  • 1em (relative) - "Hello, I am learning HTML." - Relative: 1em = the parent font size. If parent is 16px, then this is 16px.
  • 150% (relative) - "Hello, I am learning HTML." - Relative: 150% of the parent font size. Similar to em but written as a percent.

Section 6: CSS Positioning

There are 4 positioning options in CSS. The footer at the bottom of this page uses position: fixed.

1. position: static - This is the default. The element just sits in normal order on the page. You cannot move it with top/left/bottom/right.

I am static - just sitting in normal flow.

2. position: relative - Moves the element from where it normally would be. I set top: 20px and left: 30px to shift it. Use this when you want to nudge something without affecting other elements.

I am relative - moved 20px down and 30px right from my original spot.

3. position: absolute - Pulls the element out of the normal flow and places it relative to its parent. I set it to top: 10px right: 10px so it goes to the top right corner. Use this for things like badges or popups inside a container.

This is the parent container (position: relative).

I am absolute - pinned to top right of my parent.

4. position: sticky - Works like relative at first, but sticks to the top when you scroll past it. Good for headers that should stay visible. Scroll in the box below to see it work.
