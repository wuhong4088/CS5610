## About

This page loads the first 50 AirBNB listings from a JSON file using JavaScript `fetch` and `await` (AJAX).

Each listing shows:
- Listing name
- Price
- Description
- Amenities
- Host name and photo
- Thumbnail image
- ⭐ Superhost badge (creative addition)
